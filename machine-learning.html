Machine Learning

Machine learning (ML) is a branch of artificial intelligence where computer systems learn from data to identify patterns and make decisions or predictions without being explicitly programmed for every scenario.

History of ML

Machine learning developed from earlier work in statistics, pattern recognition and computer-based decision-making. Early machine-learning research included methods for recognising patterns and making predictions.

  • Researchers explored ways for computers to learn useful patterns from data rather than relying entirely on rules written by people.
  • Rule-based machine learning and decision rules also became important parts of the field during the 20th century.
As research progressed, machine learning increasingly focused on algorithms that could build models from example data. Instead of specifying every decision directly, a programmer could provide data and a learning method.
  • During the later 20th century, machine-learning methods were developed for pattern recognition, prediction and classification.
    • These methods became increasingly useful as computing resources and digital data increased.
  • By the 2000s and 2010s, machine learning had become widely used across technology and research.
  • It is now applied to text, images, speech, medical information, finance, recommendation systems and many other orms of data.
In SAGEXP, the wearable's classifier follows the main idea of machine learning: learning patterns from examples so that a trained model can make predictions about new measurements.

How ML works

Machine learning allows a computer to learn patterns from data and examples instead of being given complete step-by-step rules for every possible situation

  • During training, it adjusts internal parameters so that predictions become closer to known outcomes in the training data.
  • Once trained, the model can receive new data it has not previously seen and use what it learned to produce a prediction.

    • The Process
    1. Data preprocessing: raw data is cleaned, organised and converted into a form suitable for the model.
    2. Training: the model learns patterns or relationships from training examples.
    3. Evaluation: the model is checked using separate data to see whether it can make useful predictions on examples it did not learn from.
    4. Optimisation: the model or its settings can be refined to improve performance.

    Machine-learning predictions are often probabilistic rather than absolute. A model may indicate how strongly the available evidence supports one category rather than claiming its prediction is certain.

Types of ML

Unsupervised Learning: The model works with data without pre-existing labels and looks for patterns or groups within the data.
Reinforcement Learning: The system learns through interaction by taking actions and receiving feedback in the form of rewards.
Supervised Learning: the model learns from labelled examples where the correct output is already known. Includes 2 main categories:

  • Classification – A supervised-learning task where the model predicts a category, such as a stress-related or non-stress category.
  • Regression – A supervised-learning task where the model predicts a numerical value rather than a category.

      • SAGEXP: The wearable stress-detection component is most directly related to supervised classification because the model is intended to classify physiological measurements into defined categories.

ML lifecycle

  1. Data Management: Collect, prepare, label and check the quality of the data used to develop the model. Useful data should be relevant to the intended task and provide enough examples of situations the model is expected to encounter.
  2. Model Learning: Choosing a suitable model and training it using the prepared data.
  3. Model Verification: Testing the trained model using separate data to assess whether it works on examples not used for training.
  4. Model Deployment: integrate the verified model into the wider system and monitor it after it is put into use.
The lifecycle is iterative rather than strictly linear. If a model performs poorly, researchers may return to an earlier stage, such as improving the data or changing the model.
